# P-ELLA Market — HNG15 Lesson 2

Built by Amaka Nwokedike as the shop website prototype for HNG 15 Lesson 2.

Current features: product catalogue, category filter, cart, quantity controls, checkout form, responsive layout and browser cart persistence.

Required next integrations: Supabase/Neon database, Mailgun confirmation email, Google authentication through Google Cloud Console, then deployment and end-to-end testing.

Never expose private API keys in frontend code.
